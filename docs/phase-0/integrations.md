# Official integration and content-trust plan

Status: Design. Live provider permissions and credentials are absent. Research date 2026-10-14; see [sources](sources.md). No scraping, unofficial APIs, shared credentials or copied unlicensed assets.

All cache policies identify service, billing jurisdiction, field, purpose, approval reference, terms revision, maximum TTL and deletion behavior. Redis/HTTP/service-worker/CDN caching is disabled for unapproved content, including error bodies that could contain provider payloads. Only approved native catalog responses and explicit permitted fields use caching. Content licensed independently from an owner can be stored without pretending its license came from Google.

Ranking and provider-derived date tags require a current terms review; using a provider response as an input does not automatically authorize storing derived content. No batch speculative Places fetch or background popularity harvesting. Outages never authorize scraping.

## Adapter contract and resilience

Typed provider port returns `available|empty|degraded|disabled|rate_limited`, items and structured warnings. Every item carries provider/external ID, original URL, author display name as provided or null, publication date or null, observation timestamp, attribution/license policy reference and allowed presentation facts. Nulls are displayed as unavailable; do not invent missing dates/authors/tags. Preserve original review meaning and translated/original variants with labels.

Transport has an egress allowlist of reviewed official API hosts, TLS verification and maximum response bytes (initially 2 MiB). Reject user-supplied fetch URLs, redirects to new hosts, metadata/private/link-local/reserved IPs, DNS rebinding and unexpected protocols. Provider image/iframe loading uses separately reviewed official origins, never an unrestricted server proxy.

Per-provider deadline 2 seconds, interactive total external budget 3 seconds; at most 2 retries of safe read calls if budget permits. Backoff full jitter uniform `[0, min(1000ms,100ms*2^attempt)]`. Retry transient network/5xx and 429 only; honor Retry-After, and return deferred status when delay exceeds deadline. Do not retry 4xx authorization/validation failures or unsafe side effects. Cancel work on request abort. Provider response schemas allow documented evolution deliberately but never accept invalid typed fields; unknown fields are stripped at the anti-corruption boundary, not blindly forwarded to clients.

Proposed circuit breaker: rolling 30-second window, minimum 10 attempts, open at >=50% transient failure; open for 30 seconds, one half-open probe, close on success or reopen on failure. Bulkhead 8 simultaneous calls/provider/instance with bounded queue 16; distributed quota budget and API expenditure limits prevent retries across replicas from overspending. Expose coarse status only, no credentials or upstream internals. Health checks do not make billed provider searches.

Do not log upstream payloads, token-bearing URLs or reviewer identities. Contract tests use redacted/fictional fixtures and frozen transport clocks/randomness. Source partial failure is a successful search with warnings when independent results exist; all discovery dependencies unavailable and no valid catalog results gives 503, not an authoritative “zero places”.

## Click-to-load surfaces

Initially render a local accessible list/map placeholder and source links. No map/social scripts, iframe, preconnect, pixels, remote thumbnails or third-party fonts before provider-specific consent and explicit load action. Consent disclosure names the provider, transfer purpose and withdrawal control. Reject all and accept all have equal prominence; map consent is distinct from geolocation and analytics. Withdrawal aborts pending fetches, removes provider iframes/scripts where possible and blocks future requests; already transferred data cannot be recalled, which the policy explains. Provider APIs are invoked only on disclosed search actions, minimizing fields and never sending the user's account identity unnecessarily.

External player content may not provide accessible captions/transcripts. Publish approved videos only when sufficient accessible alternatives exist (creator-supplied captions/transcript or equivalent licensed text). Otherwise present the source link with limitation and do not claim its third-party player is WCAG-compliant.

## Moderation, reviews and images

Native reviews require verified-account status, accepted content license/version and disclosed incentives; launch policy prohibits incentivized reviews rather than encouraging them. A verified account is not a verified visit. Allow negative opinions; no buying/writing/incentivizing/removing sentiment-selected reviews. Publish community rules, transparent notice-and-action and appeals with audit trails. Provider review subset/order is labeled as provided, not a complete evidence base.

Heuristics flag, never automatically proclaim fraud: normalized duplicate text, >=5 reviews for one native place within 10 minutes from distinct recently created accounts, and abnormal distribution shift with minimum sample size 20. Thresholds are initial hypotheses requiring tuning and bias review. Native duplicate detection uses limited keyed fingerprints retained only for moderation purpose. Google response sample alone is too limited for reliable burst/distribution detection; do not persist prohibited review text/fingerprints to make these heuristics possible. Refer provider abuse through official reporting/source links. Moderators review evidence, issue reasoned decisions and notify authors/complainants where lawful; legal takedown can restrict content but reputation management cannot.

Image uploads use a server-issued single-use quarantine target, max 10 MiB, <=40 megapixels, JPEG/PNG/WebP allowlist; no SVG/HTML or animated media initially. Sniff magic bytes and decode fully, reject polyglots/decompression bombs, scan with maintained malware signatures, re-encode stripping EXIF/metadata, compute dimensions/hash, verify explicit license grant and required alt text, then promote atomically to private licensed storage/CDN. Scan failure or timeout keeps image quarantined. Signed serving URLs have short expiry; originals are not exposed. Apply retention/deletion to derivatives and quarantine. Videos are official embeds rather than unvalidated uploads until a separately reviewed upload pipeline is enabled.

Image attribution includes source, license/grant, provided author/date, original URI and neutral “Photo of {place}” alt fallback if a reliable descriptive caption is unavailable. Do not generate factual claims about accessibility/romance from image appearance. Licensed native image transforms use responsive AVIF/WebP with dimensions; provider images follow provider delivery restrictions. Report/takedown endpoint supports rights evidence and appeals, with no automatic malicious reporter suppression. Avoid cross-provider aggregation of star ratings; optional summaries remain off until labeling, source links and hallucination/meaning tests pass.
